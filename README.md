# Heartfunds Website

A responsive, single-page company website for Heartfunds using plain HTML, CSS and JavaScript.

## Structure

- `index.html` — complete website
- `assets/css/style.css` — theme, responsive layout and animations
- `assets/js/main.js` — navigation, scroll reveal, active sections and lightweight effects
- `assets/images/logo.png` — your supplied Heartfunds logo
- `assets/images/founder-harish.jpg` — add Harish's photo here
- `assets/images/founder-idhayanithi.jpg` — add Idhayanithi's photo here
- `assets/images/founder-faizul-ahmed.jpg` — add Faizul Ahmed's photo here

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing

1. Add the two founder images with the exact filenames above.
2. Replace `hello@heartfunds.quest` if you want another contact address.
3. Update the product/service copy as the company evolves.
4. Add real social-media/company links in the footer when available.

The animations are intentionally CSS/IntersectionObserver based so the page stays lightweight and smooth. No animation framework is required.
